# 연출 스킵

연출 중 Enter 또는 숫자패드 Enter를 한 번 누르면 화면이 암전되고, 최종 상태 적용 후 화면이 복귀한다. 화면 복귀 후 플레이어 조작과 전투가 시작된다. 스킵 중 재입력은 무시한다.

- `ActingScreenFade`: 검은 화면 생성, 암전과 복귀만 담당한다. 타임 스케일에 영향을 받지 않는다.
- `ActingController`: 현재 연출 등록, 스킵 입력, 취소·최종 상태 적용·전투 시작 순서를 담당한다.
- `PlayerStatusManager`와 `GameStartActing`은 하나의 시작 연출로 취급한다. 어느 구간에서 스킵해도 보스1 전투로 넘어간다.
- `Phase1ToPhase2Acting`은 배경·불·보스 교체까지 완료하고 보스2 전투로 넘어간다.

## 연결

`PlayerStatusManager`가 같은 오브젝트의 `ActingController`를 사용하며, 없으면 실행 시 추가한다. 컨트롤러는 `ActingScreenFade`도 자동으로 추가한다. 씬과 프리팹을 수정하지 않아도 기존 연출 시작 함수에서 자동 등록된다.

암전 시간을 Inspector에서 조절하려면 플레이어에 `ActingController`와 `ActingScreenFade`를 미리 추가한다. 기본 암전과 복귀 시간은 각각 0.25초다. 보스와 HP UI 참조는 미지정 시 씬에서 검색하므로, 같은 종류의 오브젝트가 여러 개 있는 테스트 씬에서는 컨트롤러에 직접 연결한다.

스킵 안내 문구는 `ActingController`의 `Skip Guide Text`에 TMP 텍스트 GameObject를 연결한다. 시작 연출과 2페이즈 전환 중에만 활성화되며, 정상 종료·스킵 시작·컨트롤러 비활성화 시 숨긴다. 텍스트 내용은 직접 설정하며, 연결하지 않아도 스킵은 동작한다.

위치와 크기는 렌더링할 카메라에 맞춰 보정한다. 월드 `TextMeshPro`와 Canvas의 `TextMeshProUGUI`를 지원한다. `Skip Guide Camera`는 비워두면 `Camera.main`을 사용한다. `Skip Guide Viewport Position`의 기본값 `(0.5, 0.08)`은 화면 하단 중앙이며, `Skip Guide Font Size`의 기본값 28은 화면 높이 1080 기준이다. 월드 텍스트는 `Skip Guide Camera Distance` 거리에서 카메라를 향한다. 텍스트 영역은 화면 너비 80%, 높이 10%로 설정하므로 LayoutGroup 등 다른 자동 배치 대상과 분리해 연결한다.

## 협업 범위

`Assets/02.Scripts/Boss` 파일은 수정하지 않는다. 보스1의 공개 정리 함수를 호출하고, 보스2는 기존 `Replay()` → `RevealBoss2()` → 화면 복귀 → `StartBattle()`을 사용한다. 현재 `Replay()`는 실제 재생 없이 내부 연출을 정리한다. 해당 함수가 앞으로 다시 재생하도록 변경된다면 스킵 연결도 함께 검토해야 한다.

이 경로에서는 보스2의 기존 `IntroFinished` 이벤트가 발생하지 않는다. 현재 인게임 씬에서 해당 이벤트가 담당하는 HP UI 표시는 컨트롤러가 직접 처리하고, 페이즈 종료는 `CompleteAfterSkip()`에서 처리한다. 다른 완료 이벤트를 추가하는 경우 스킵 경로에도 연결해야 한다.

## 플레이 모드 확인 항목

- 플레이어 준비, 보스1 착지 전·후에서 각각 스킵: 위치, 카메라, 조명, HP UI, 조작과 보스 공격을 확인한다.
- 2페이즈 전환 직후, 소등 중, 배경 변경 중, 보스2 얼굴 및 이름 연출 중에 각각 스킵한다.
- 화면 복귀 후 보스1이 남아 있지 않고, 붉은 불·배경·보스2·HP UI·BGM이 정상인지 확인한다.
- Enter를 연타하거나 누르고 있어도 완료 처리가 중복되지 않는지 확인한다.
- 스킵하지 않은 정상 연출도 전투까지 이어지는지 확인한다.

컴파일 검증과 플레이 모드 검증은 별개다. 이 변경은 컴파일을 확인했으며 위 플레이 모드 항목은 별도로 확인해야 한다.
