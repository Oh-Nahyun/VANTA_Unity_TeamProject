# \# VANTA : LAST LIGHT

# 

# > \*\*보스의 패턴을 파악하고, 회피와 반격으로 돌파하는 2D 액션 보스 러쉬 게임\*\*

# 

# \*\*VANTA : LAST LIGHT\*\*는 보스의 공격 패턴을 관찰하고 학습하며,  

# 정확한 회피와 근거리 공격을 통해 보스를 공략하는 \*\*2D 액션 보스 러쉬 게임\*\*입니다.

# 

# 빠른 전투 흐름 속에서 \*\*묵직한 타격감과 속도감\*\*을 전달하는 것을 핵심 목표로 합니다.

# 

# \---

# 

# \## 🎮 Game Overview

# 

# | 항목 | 내용 |

# |---|---|

# | \*\*게임명\*\* | VANTA : LAST LIGHT |

# | \*\*장르\*\* | 2D Action / Boss Rush |

# | \*\*플레이 방식\*\* | 보스 패턴 파악 → 회피 → 반격 |

# | \*\*핵심 Feel\*\* | 묵직한 타격감 / 속도감 |

# | \*\*플레이 구조\*\* | Boss Battle → Clear / Retry |

# 

# \---

# 

# \## ⚔️ Core Gameplay

# 

# 플레이어는 보스의 공격 패턴을 관찰하고 대응 방법을 학습해야 합니다.

# 

# 보스의 공격을 \*\*회피하여 공격 기회를 만들고\*\*,  

# 근거리 무기 공격과 스킬을 이용해 보스에게 피해를 입힙니다.

# 

# 또한 \*\*펫의 보조 능력\*\*을 활용하여 전투를 유리하게 이끌 수 있습니다.

# 

# \### Core Loop

# 

# ```text

# 보스 조우

# &#x20;  ↓

# 보스 패턴 관찰

# &#x20;  ↓

# 패턴 파악

# &#x20;  ↓

# 회피 / 위치 선정

# &#x20;  ↓

# 반격

# &#x20;  ↓

# 보스 피해

# &#x20;  ↓

# 다음 패턴

# &#x20;  ↓

# 반복

# ```

# 

# 보스의 HP가 0이 되면 전투에서 승리하며,  

# 플레이어의 HP가 0이 되면 전투를 재도전합니다.

#

# |---|---|

# | `WASD` | 캐릭터 이동 |

# | `Mouse Click` | 무기 공격 / 스킬 |

# 

# \---

# 

# \## 👹 Boss Battle

# 

# \### Boss Encounter

# 

# 전투 공간에 진입하면 보스 등장 연출과 함께 전투가 시작됩니다.

# 

# 전투 시작과 동시에 보스 HP 및 전투 UI가 활성화되며,  

# 연출을 통해 보스의 특징과 전투 분위기를 전달합니다.

# 

# \### Pattern Learning

# 

# 보스는 \*\*2개의 페이즈\*\*를 가지고 있으며,  

# 각 페이즈에서 여러 공격 패턴을 반복하거나 조합합니다.

# 

# 플레이어는 전투를 반복하면서

# 

# \- 공격 방향

# \- 공격 범위

# \- 공격 타이밍

# \- 안전한 위치

# \- 반격 가능한 타이밍

# 

# 을 학습하게 됩니다.

# 

# \### Dodge \& Counter

# 

# 보스의 공격 방향과 범위를 파악하여 회피하고,  

# 스킬과 이동을 활용해 유리한 위치를 확보한 뒤 반격합니다.

# 

# 정확한 회피에 성공하면 생존뿐만 아니라  

# 보스에게 공격할 수 있는 새로운 기회를 확보할 수 있습니다.

# 

# \### Boss Clear

# 

# 보스의 HP가 `0`이 되면 전투가 종료됩니다.

# 

# 보스 처치 연출 이후 클리어 화면으로 전환하여  

# 플레이어에게 승리 결과를 명확하게 전달합니다.

#

# \## 💥 Game Feel

# 

# VANTA : LAST LIGHT는 단순히 공격 데미지를 전달하는 것을 넘어  

# \*\*공격이 실제로 적에게 꽂히는 느낌\*\*을 전달하는 것을 목표로 합니다.

# 

# | Feel 요소 | 구현 방식 |

# |---|---|

# | \*\*Hit Stop\*\* | 공격 적중 순간 게임 시간을 짧게 정지시켜 충격 강조 |

# | \*\*Camera Shake\*\* | 공격 강도와 상황에 따라 카메라 흔들림 적용 |

# | \*\*Slow Motion\*\* | 아슬아슬한 회피 및 보스 처치 순간 슬로우 모션 적용 |

# | \*\*Trail / AfterImage\*\* | 공격, 대시, 회피 시 궤적 및 잔상 표현 |

# | \*\*Knockback / Recoil\*\* | 공격 적중 시 캐릭터와 보스에 짧은 반동 적용 |

# | \*\*Hit Effect\*\* | 공격 위치에 스파크 및 충격파 VFX 생성 |

# | \*\*Attack / Hit SFX\*\* | 공격·적중·회피·피격 상황별 효과음 적용 |
